# Maro's Workshop

This project contains two connected Bauhaus-style creative coding scenes:

1. Pattern Studio — compose generative drawings from prepared shapes.
2. Algorithm Art Studio — Wave, Bloom, Multiply, and Create.

Scene 02 lets campers draw a personal seed mark, transform it with visual
algorithm controls, watch it execute, revise a Before version into an After
version, title/export the artwork, and inspect both the ordered pseudocode and
the operation definitions through the `<Code>` window.

## Run locally

```bash
npm install
npm run dev
```

Open the local address shown in the terminal. For a production check:

```bash
npm run build
```
